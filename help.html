Help, corrections and accessibility

Help & feedback

Found an error, have a better source, need an accessibility fix or think something important is missing? Send it in.

Report an error or suggest an improvement

Use the site's feedback form for incorrect information, outdated information, a broken link, missing context, an accessibility problem or a feature request.

Give feedback

Please do not include private information, home addresses, personal phone numbers or anything else you do not want included in an email.

For candidates, campaigns and public officials

If something attributed to you is inaccurate, identify the exact page and wording and provide the strongest available source showing the correction. A campaign statement is useful for explaining your position; an official record or primary document is preferable when the dispute concerns a vote, decision, filing or other verifiable event.

Correction and removal requests are reviewed consistently. A request alone does not guarantee removal. When relevant to the public record, the site may transparently note that a request was received and what changed, without publishing private contact details.

Accessibility

The site is intended to work with keyboard navigation, browser zoom, screen readers and common accessibility settings. It includes a skip link, visible keyboard focus, semantic headings and navigation, reduced-motion support, and light/dark appearance controls.

If a page, comparison, control or source link is difficult to use with assistive technology, report the page and what happened. Accessibility issues should be treated as bugs and fixed when practical.

How the guide is built

The project uses public candidate information, government records, reporting and clearly labelled public discussion. Automated monitoring can flag source changes for review, but it should not automatically turn internet sentiment or a changed webpage into a political claim on the live guide.

The goal is a growing, source-backed record that can show what candidates said, what decisions were made and what changed over time while keeping facts, campaign claims and public opinion distinct.
